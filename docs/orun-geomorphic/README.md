## 分布方式

64、256、1024、4096 米的坡度、凹凸、相对高低与平面拟合残差区分不同地形。材料按多个下坡方向分流，携带三种母岩来源；粗、细碎屑的迁移尺度为 256 米和 2048 米。封闭低地保留沉积，并记录边界流出量。

裸岩接触保留清楚的界限。薄尘继承邻近风化物的混合来源，随覆盖厚度逐渐遮住母岩；碎屑沿地形进入坡脚与浅沟。岩性相同的材料保持连续，细小亮度扰动限制在约 ±1%。

五类覆盖最终归并为六组母岩／风化颜色权重。每面按固定 16 米基元积分，远处读取预积分权重。颜色滑条只更新六组调色值，沉积位置与地形保持固定。AO 使用连续地形八个方向、64–4096 米范围的遮蔽近似，独立影响间接光。每面使用统一的粗糙度。

## 验证

- [数值测试](unit-verification.json)：平面、来源与收支、浅坡转向、四尺度、LOD 积分、调色、旧参数、地形保护及软硬边界。
- [当前资产对照](source-verification.json)：137,710 个地形柱的位置、法线和索引逐块哈希一致；生态和水体权重最大差约 7e-18。
- 103 个平地采样位置的 16 米颜色差异平均下降约 95%。这是固定样本的数值比较，不代表全图质量评分。
- [浏览器验证](visuals/verification.json)：13 张画面、无页面错误与缺失资源；包含取消重算、材质检查器、旧版切换和窄窗口。
- 测试机 Chrome 无界面渲染：首次展开 36.5 秒，机位采样约 59–60 fps；调色不重建场景，接口测试约 10 毫秒。初始 JavaScript 堆快照约 747 MB，不是完整 GPU 内存。
- 完整默认材料预计算约 142 秒，其中地形分析与碎屑迁移约 20 秒，其余为全区域积分；网页直接使用预计算结果。

## 使用与复现

打开“地貌材质”控制组；关闭第一项可回到原有配色。原有噪波调色控件只在旧模式显示。版本 1–3 参数文件默认保留旧模式，版本 4 记录新算法。分布重算在 Worker 中执行，期间保留画面，可随时取消。

[默认参数](parameters.json) · [预计算记录](generation.json) · [无光照颜色](visuals/albedoRaw.png) · [覆盖](visuals/surfaceCover.png) · [来源](visuals/surfaceSource.png) · [冲刷与沉积](visuals/surfaceWash.png) · [遮蔽](visuals/surfaceAO.png)

独立生成入口：源目录中的 src/build-orun-surface.cjs；Showheel 中对应 scripts/build-orun-surface.cjs。传入 atlas 目录重建，增加 --check 只核对输入及预计算哈希。

该模型计算相对覆盖和材料迁移，保留现有地形，未做新的地形侵蚀或完整土壤动力学求解。细于最小方块的差异进入平均颜色。预积分／实时积分的当前材质场最大线性 RGB 差约 1e-8。

## 发布

Orun 使用独立依赖清单，保留其它地图已有发布副本。修复了 Character 适配器对非目标文件进行文本编码的问题，二进制现在原样复制。压缩包包含 4681 个文件及 10 个页面，总计 777.44 MB；解压哈希、模型与中英文正文哈希已通过校验。压缩网站浏览器结果另见 packed/verification.json。

首次生成的 compressed-site 为编码问题的诊断留档；有效发布包是 compressed-site-v2。
