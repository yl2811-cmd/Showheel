# Atheria 树冠与 Orun 全崖迎风带

2026-09-13。本轮按用户最新要求只做本地完成与 Showheel 同步，暂不压缩、不提交、不推送 GitHub，也未触发部署。

Atheria 使用全域 2.5× 默认树冠面积，田野与 terrace 的增量权重为 4∶1。固定世界坐标上的密度噪波形成疏树和少量密林；地面树冠高 10–20 米，低覆盖率改变占地而不把整片树冠压成草地台面。正常疏树冠之间约留二十几米；terrace 保持独立的 6 米平均树高。树冠材质具有稳定的细微分形色差。树密度单独调整，不重算屋群。定量覆盖与支撑面、通道裁切、远景面积归并检查通过。浏览器当前画面无错误，约 16.7 ms/帧。

Orun 的整个北向和西北向崖前作为迎风带处理，降雨补给、湿润低地和岩阶绿植沿全线展开；局部 50 km 内继续使用已验证的局部生态结果，50–57 km 接缝平滑过渡。高原顶与背风面保留干燥斑块。地图生态颜色已排除水体颜料，消除河岸偏白细纹。

区域河网共 15,154 段，另有 2,291 段共享局部河网；12,235 段最终汇入 Ishkar。检查无重复 ID、断链、循环或逆坡。主河、城镇、路线、崖线与原始备份逐项一致。部分实际闭洼和其他原有流域保留，不把所有水系强行连接到 Ishkar。

World map、Aethelgard 的页面、六份 SVG 和六份 PNG 已更新。星球 4096×2048 等距经纬贴图按相同地理坐标叠加世界图的同一生态图层；33,537 个纹素发生变化，投影取样误差为零，原始地表和湖泊数据保持不变。地标的“在球面上看这个地方”现在能正确定位 Orun。
