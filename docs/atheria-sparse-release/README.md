# Atheria：发布用户确认的疏林参数

2026-09-13 从用户当前预览页面读取并固定：城区 0.68×、田野下限 0.07×、田野上限 0.10×、矮树倾向 4.0。默认关闭原版对照；自然林及河岸沿用 1.7× 基线。

覆盖依照现有聚落、田野和河岸分区计算。城区优先于田野，边缘平滑衔接；田野沿固定世界坐标的 180／720 米噪波变化。不会将田野减少的覆盖量重新补到其他区域。

程序生成树高仍为 6–20 米，以 `6 + 14 * ((原高度 - 6) / 14)^4` 偏向较矮树木。保留原种子、颜色、方块表达、面积采样和着色器；鹰巢精细模型、房屋及地形不改动。

压缩资源读取统一转换为字节数组，避免把 ArrayBuffer 当作带有 buffer 属性的数组而读到空高度／覆盖数据。此修正不涉及着色器。

页面保留分区控制及“对照原版 1.7×”。新的默认值使用独立保存键，避免旧全域滑杆或此前试验参数覆盖发布默认值。保存参数按钮导出独立 JSON，不覆盖屋群方案。

## 验证记录

- `accepted-parameters.json`：读取自用户确认页面的参数。
- `parameter-verification.json`：覆盖积分 约 127.78 km²，与页面一致；颜色输入保持不变。面积表示模型覆盖积分，不是截图像素或独立树木数量。
- `source-verification.json`：着色器片段及房屋、地形等基线输入哈希。
- `sync-verification.json`：限定文件同步，其余 4,592 个地图资源保持不变；中文 Timelapse 原样同步，英文正文不变。
- `compression-summary.json`、`browser-verification.json`：本次压缩完整性与实际浏览器检查。
