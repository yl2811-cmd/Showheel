# Atheria 与鹰巢合并 · 2026-09-10

鹰巢高精度场景接入 Atheria 的原点，保留原始米制比例、房屋、崖壁、溪流和陈设。原始 1,060 份几何与 25,737 份实例数据保留；十个二进制包逐份与源文件校验一致。接入圈外增加与区域地面相接的细体素过渡层。

独立的「06 鹰巢」入口已从页面移除。Atheria 内提供鹰巢近景、完整崖壁、溪流与崖脚机位；旧的 #view=eyrie 链接转入合并后的近景。滚轮朝指向处靠近，双击可重新设定旋转中心。独立原始模型仍留在作者源目录，发布清单排除重复的旧几何。

北侧大河沿岸改成宽缓高地。北支从大河约 360 m 的接点降至约 296 m 的上层阶地，并接入鹰巢溪流；17 条河道的水面高度检查均沿流向下降。原有屋群平面布局保留。
