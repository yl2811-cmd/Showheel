# Atheria · 两组互不重合的小屋变化

算法版本 detached-house-mix-v8。默认小屋总数保持5820栋：2328栋（40%）整栋宽、深、高均放大1.4倍；另外1164栋（20%）增加2–3个相连侧体；剩余2328栋保持原形。两组互斥，选择与细节均由稳定编号决定，不随镜头重抽。

## 几何与安全边界

整体放大保留原有体块组合和比例，新增侧体有不同宽窄、错进和高度，沿外缘相接。复合房屋整栋最多10块，原本已达9块的退台不进入侧体扩建组。地形承托、碰撞、既有搜索距离及田地15%占用上限按最终包络重新检查。无法安置的候选保持原样，并继续在稳定顺序中寻找可用对象。

补查了当前房屋周边42549个承托包络，采样间距不超过6米，显示地形高差≤1米、自然地形高差≤3米，并排除通路、水岸、保护对象及边缘。补查只增加已验证的承托范围，不改变地形、道路或保护对象。

两组均已达到默认目标，来源房屋没有删除。新增体积单独记录为12323016.003立方米，原有尺寸下限、降高及退台增量记录保留。继承此前普通房屋的逻辑体积，再计入整体缩放和新增侧体体积；显示细节体块不当作额外房屋计数。

格距≤25米时显示各栋实际体块，>25米时使用同位置、同包络和同最高点的单个体块。整体放大后允许超过原始拆出块的24米生成尺寸，最终尺寸仍经过安全安置检查。12米整屋下限、默认偏高比例25.53%及原有terrace错落感保持。

## 验证与使用

16项尺寸、碰撞、四级绘制和保护检查，6项互斥分组与几何专项检查，33组滑条端点检查，以及浏览器保存载入、撤销复位、压缩网页和独立导出一致性检查通过。极端参数不能满足已有屋组尺寸时仍会拦住候选发布。
