# 超新星物理与预警逻辑补充

本轮在 timelapse 中完成 23 处定点替换。长期观测和防护判断、人类进入前的复核、短期中微子警报与 Axiom 的多年准备窗口已分开；同时统一了 Intro 中的对应说法。

## 已写入的逻辑

- 2472 年起便有总监 ASI，早期无人阶段减少的是人类暴露，不降低判断系统的能力或人格智能的地位。
- 2538–2550 年重新复核恒星风险；继续推进依靠当时认为足够的 II-P 防护和灾后人居延续能力。
- 对表面与外流的连续观测不等于核心阶段被反复独立确认；保留晚期核心解释，避免把伴星并合写成跳过核演化的开关。
- 近星观测加曲速信使在技术上可行，但并未配置成持续可用的预警链；小型信使的现有 canon 保留。
- 中微子的传播延迟不抹去源端提前量。Intro 的临近警报促成最后撤入，Axiom 则提供多年的建造与分散保存时间。
- Axiom 在 dogleg 之前实际进入首包；当时源区已有部分回亮，但其光尚未抵达交会位置。
- 回亮辐射、宇宙射线、物质激波、当年持续发光分别处理；承认退出曲速等待和常规无人探测的替代方案。
- 信使的 2571 年外侧离开可避免已有光壳；退出与重启不再被写成所有任务共有的禁令，也不提前揭示信使命运。

## 科学依据

- [KamLAND 与 Super-Kamiokande 爆前联合警报](https://arxiv.org/abs/2404.09920)：支持末期中微子预警机制；论文特定地球模型的小时数未搬入 Archeon。
- [碳燃烧红超巨星中微子](https://arxiv.org/abs/2502.05404)：低能谱、本底与探测规模；十光年与二百秒差距通量比由距离平方自行核算。
- [致密星周相互作用的光学至 X 射线表现](https://arxiv.org/abs/2109.09746)：冷却和吸收会改变逃逸频谱与峰值时间。
- [Alcubierre 度规中的粒子轨迹](https://arxiv.org/abs/1202.5708)：仅作为粒子相互作用的理论参考，不作为可用曲速工程的证明。
- [近邻超新星对大气与生物圈的影响](https://arxiv.org/abs/1702.04365)：磁场方向和次级粒子的影响；其 50 pc 地球模拟剂量未直接用于本作十光年环境。
