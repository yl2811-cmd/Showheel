# Atheria · 12米小屋与向外退台

算法版本：detached-terraces-v7。默认滑条数值保持。默认共有5820栋分散小屋，1486栋在外扩前的高宽比超过0.8，占25.53%，低于35%。这些小屋均已形成退台；没有无法满足12米下限的已有小屋。

## 尺寸与轮廓

整屋短边a≤10时取12米；10<a<14时取12+(a−10)²/8米；a≥14时保持。整栋同比缩放，不把每个内部voxel放大到12米。原有采样边界造成的屋身碎片按统一建筑身份处理；已有完整的复杂屋组保留内部构造。

高宽比r≤0.4的低矮段保持；其余采用0.4+(r−0.4)/(1+1.22×(r−0.4))。系数根据默认布局校准并固定，不随镜头或普通重算改变。手动调高滑条仍可超过35%的默认占比目标。

偏高屋保留降高后的中央主体，四侧增加以65%高度为中心、实际58–72%的侧体；按稳定编号加入零、两或四个以40%为中心、实际34–46%高度的角部体块，并让四边退让宽度略有不同，形成5、7、9块退台。1310栋宽深外扩15%，83栋外扩10%，93栋外扩5%。原本低矮的部分不继续压低，原有terrace核心与受保护的鹰巢等对象不套用此规则。

格距≤25米时，普通矮屋主要2–3块，偏高屋5–9块；>25米时使用单个固定包络体块，位置、宽深及最高点不变。全城细节数量为：单块154栋、两块1369栋、三块2811栋、五块493栋、七块469栋、九块524栋。内部块数不计为额外房屋。另检查154个至少12栋小屋的500米区域，按实际体块轮廓、尺寸、高度和来源颜色核对重复组合，结合近景检查保留错落感。

## 安置与体积

已有小屋优先，按实际包络验证承托、碰撞、150/250米既有搜索范围及田地15%额外占用。依次尝试15%、10%、5%外扩；已有屋无可用外扩位置时保留安全原形并报告，新增或拆出屋放不下则减少生成。来源切口只在搬移成功后接受。

尺寸下限增加体积2291637.350立方米；最终小屋的基线降高减量5094158.001立方米，退台外扩增量822696.964立方米。各阶段记录独立保存，拆解核验包含这些明确的增减，纯搬移与收回继续核验占地守恒。LOD统计使用统一逻辑几何，不使用粗景显示包围盒计算体积。

默认实际拆解2345组，其中terrace 116组；terrace实际外围拆出中位数约10.0%。新增体积需要额外空地，所以搬移数量仍受实际安全落点限制。

## 验证

16项原有尺寸与几何检查、8项退台专项检查、33组全城滑条端点检查通过。包括曲线连续单调、低矮段不变、12米整屋下限、最多9个相接体块、无新增碰撞、狭窄落点回退、无落点保留已有屋，以及9.85/19.69/25/25.01/32米阈值。

浏览器撤销、复位、保存载入、旧版提示重算及非默认参数计算通过；预览与独立导出的房屋及更改记录经序列化后完全一致。少数极端收回/搬移设置无法保持合法屋组尺寸时会阻止该候选发布，默认布局无此阻塞。
