# 岩层、河谷与沙地：本地候选

当前保存底稿为 v10，七个叙事级板块与 0.98g 保留。新一轮分别运行纯侵蚀和间歇造地，正式地图与正文未覆盖。

## 本轮结果

- 三个种子、四个地区、两种过程：24 组 16 km / 200 万有效年对照。
- 已完成 48 组局部试算；各视图注明实际网格与时长。Atheria / Frontier 的 2 km 缓地核对采用 10 万年，宏观对照仍为 200 万年。
- Orun 与 Marneth 使用独立的保护地貌侵蚀试验；聚落核心和 Orun 两端保留。较新 Orun 的完整硬盖层与 Marneth 较薄的残余盖层是本轮工作假设。
- 岩石转成土砂、流水侵蚀、沉积、坡面搬移和向海输出分别记账。岩性差异加强了谷壁与台缘的选择性侵蚀。
- 初始地形的 DEM 细部与后续物理过程分开保存。DEM 使用已有美国地质调查局高程材料的裁切与旋转，不是 Archeon 实测地形。

## Riverbend 与海岸

- Riverbend 的候选锚点移至 -9.681226°, 8.826584°。它距已选河道参考点约 1118 m；完整城镇范围与洪水安全尚未由本轮确定。
- Ishkar 采用已选形成试验的下游河段，接入初始数值河床。历史试验的整条河仍未通过完整空间收敛，不能据此声称只有一种地质历史。
- 未受保护的既有沿海洼地允许进水，不为维持旧海岸而填高。新岸线与初始进水范围分别统计；细化海湾与河口继承父级水沙及边界高程。
- 深海床只是本轮近岸计算的外部边界假设。浏览器的海面显示在 0 m，不把这套假设当成测得的海底地形。
- 航线几何留到地形选定之后重绘。

## 边界

当前降雨和风是地貌筛选条件，尚未经过真实环流校核；砂质覆盖不等于已验证的沙漠边界。没有把冰盖、气候反馈、Year 521 植被或航线当作已完成内容。

全数值场、缓存和中间快照保留在本地。网站只读取烘焙图与预览网格。本轮不做压缩构建、提交或推送。

模型说明：[Landlab SPACE](https://landlab.readthedocs.io/en/latest/tutorials/landscape_evolution/space/SPACE_user_guide_and_examples.html)。

局部空间检查：Orun 同一岩坡从250m细化至125m和64m，10万有效年的内部高程RMS差约0.33–0.35m，相对本次微小演化量约22%，尚未达到预设10%门槛。该组作为分辨率敏感性记录，不能据此声称细微侵蚀量已经收敛。

Ishkar上游衔接已另做2km/10万年试算：从保留上游锚点最近的网格节点出发，距原锚点1134m，接近已选下游河道159m；这属于当前网格内的局部连接，不替代整条河历史的空间收敛。
