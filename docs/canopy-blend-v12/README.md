# Atheria 树丛宽高比混合

按树丛的有效短边与成熟树高之比，在 0.25–1 范围内平滑过渡；长宽均达到树高时完全使用完整树冠块。细长条状树丛使用实际占地面积除以长边判断宽度，避免被当作宽阔林团。

窄树丛以附近实际田块、草地的材质色为底，混合树冠色与平均高度；比例增大时逐渐收回到实体树冠的范围与高度。混合前后保持覆盖面积、颜色增量和面积加权树高一致。过渡在世界坐标中计算后再沿地形台阶裁切，因此支撑面分块不会改变树丛的表达。房屋旁与 terrace 使用同一规则，成熟树高和原有树林总量参数保持独立。

密度数据仍为 canopy-v11，默认全域 2.5×、田野与 terrace 权重 4∶1 保留。增加的 appearance v12 只改变显示。近景混色读取实际地面顶面的颜色；细微分形材质色差保留。

四项针对过渡的检查及九项既有树冠检查通过。浏览器 farmland 画面无错误，加载完成，约 16.7 ms/帧；首次检查约 534 万三角形。树冠量没有用可见方块数量替代计量。
